Every order you fulfill through Hitayu ERP follows a structured shipment lifecycle managed via Shiprocket. From the moment you push an order to the courier network to the final delivery scan at the customer's door, each stage is tracked in real time and surfaced in the Hitayu ERP interface. This page walks you through every step of that journey, explains every status your shipment can reach, and shows you how to take action at each stage.

## Pushing an Order to Shiprocket

Before a shipment exists, you must push the order from Hitayu ERP to Shiprocket to register it with the courier network.

<Steps>
  <Step title="Open the Order Detail">
    Go to **Orders** and click on the order you want to ship. The order should have a confirmed payment status (Paid or COD) before shipping.
  </Step>
  <Step title="Click Push to Shiprocket">
    In the **Shipment** section of the order detail page, click the **Push to Shiprocket** button. Hitayu ERP sends the order details — items, weight, dimensions, pickup location, and delivery address — to the Shiprocket API.
  </Step>
  <Step title="Shiprocket Order Created">
    If successful, a Shiprocket order is created and the shipment status changes from **Pending** to **New**. You will see the Shiprocket Order ID appear on the page.
  </Step>
</Steps>

<Warning>
  Once a shipment reaches the **Picked Up** status, the order items and amount can no longer be edited. Make sure the order details are correct before pushing to Shiprocket.
</Warning>

## AWB Assignment and Label Download

After a Shiprocket order is created, Shiprocket assigns an Air Waybill (AWB) number — the courier's unique tracking identifier for the package.

<Steps>
  <Step title="AWB Assigned">
    Shiprocket automatically assigns an AWB and a courier partner based on your settings. The shipment status updates to **AWB Assigned** and the AWB number appears on the order detail page.
  </Step>
  <Step title="Download the Shipping Label">
    Once the status is **Label Generated**, click **Download Label** on the order detail page or from the **Ready to Ship** tab on the Shiprocket page. Print and affix the label to your package.
  </Step>
</Steps>

## Manifest Generation and Pickup Scheduling

A manifest is the handover document given to the courier's pickup agent. Generating a manifest schedules your packages for pickup.

<Steps>
  <Step title="Generate Manifest">
    On the order detail page (or from the Shiprocket **Pickups & Manifests** tab), click **Download Manifest**. This triggers manifest generation in Shiprocket and updates the status to **Manifest Generated**.
  </Step>
  <Step title="Pickup Scheduled">
    Shiprocket schedules a courier pickup. The status moves to **Pickup Scheduled** or **Pickup Queued** depending on whether the pickup slot has been confirmed.
  </Step>
  <Step title="Pickup Exception (if any)">
    If the courier attempted pickup but couldn't collect the package (e.g., nobody was available), the status changes to **Pickup Exception**. You'll need to reschedule the pickup from your Shiprocket dashboard.
  </Step>
  <Step title="Picked Up">
    When the courier collects your package, the status updates to **Picked Up**. At this point the shipment has left your premises and is in the courier's possession.
  </Step>
</Steps>

## In-Transit Stages

Once the package is with the courier, it progresses through several in-transit statuses.

| Status | What It Means |
|---|---|
| **In Transit** | Package is moving through the courier's network between facilities. |
| **Reached Destination Hub** | Package has arrived at the delivery hub closest to the customer. |
| **Out for Delivery** | Delivery agent has picked up the package for delivery today. |
| **Undelivered** | Delivery attempt was made but unsuccessful. May escalate to NDR. |
| **NDR** | A formal Non-Delivery Report has been raised. See the [NDR & RTO guide](/shipping/ndr-rto). |
| **Exception** | An unexpected issue has occurred (damaged package, lost in transit, etc.). Contact Shiprocket support. |

## Delivery Confirmation

When the package is successfully delivered, the status updates to **Delivered**. This triggers:

- The order status in Hitayu ERP moving to **Delivered**.
- COD remittance tracking (if applicable) becoming active.
- The option to **Create Return** appearing on the shipment detail for post-delivery returns.

## All Shipment Statuses Reference

The table below covers every status a shipment can have in Hitayu ERP, grouped by the Shiprocket stage tab where it appears.

### New
| Status | Label | Description |
|---|---|---|
| `pending` | New | Order has been created but not yet pushed to Shiprocket. |
| `created` | New | Shiprocket order has been registered. |
| `new` | New | Shiprocket has acknowledged the order. |

### Ready to Ship
| Status | Label | Description |
|---|---|---|
| `awb_assigned` | AWB Assigned | A courier and tracking number have been assigned. |
| `label_generated` | Label Generated | The shipping label is ready to download and print. |

### Pickups & Manifests
| Status | Label | Description |
|---|---|---|
| `manifest_generated` | Manifest Generated | Manifest created; pickup has been requested. |
| `pickup_queued` | Pickup Queued | Pickup request is in the courier's queue. |
| `pickup_scheduled` | Pickup Scheduled | Pickup time slot has been confirmed. |
| `pickup_exception` | Pickup Exception | Courier was unable to collect the package. Reschedule required. |
| `picked_up` | Picked Up | Package collected by the courier. |

### In Transit
| Status | Label | Description |
|---|---|---|
| `in_transit` | In Transit | Package is moving through the courier network. |
| `out_for_delivery` | Out for Delivery | Package is with the delivery agent for today's attempt. |
| `reached_destination_hub` | Reached Destination Hub | Package is at the local delivery hub. |
| `undelivered` | Undelivered | Delivery attempt failed. |
| `ndr` | NDR | Non-Delivery Report raised. Action required. |
| `exception` | Shipment Exception | Unexpected issue; contact the courier. |

### Delivered
| Status | Label | Description |
|---|---|---|
| `delivered` | Delivered | Package successfully handed to the customer. |

### RTO
| Status | Label | Description |
|---|---|---|
| `rto` | RTO Initiated | Return to origin has been triggered. |
| `rto_in_transit` | RTO In Transit | Package is on its way back to your pickup address. |
| `rto_delivered` | RTO Delivered | Package has been returned and received at your location. |

### Other
| Status | Label | Description |
|---|---|---|
| `cancelled` | Cancelled | Shipment has been cancelled in Shiprocket. |

## Syncing Shipment Status

Hitayu ERP receives automatic status updates via the Shiprocket tracking webhook. If you ever need to force a manual refresh:

- **Sync a single shipment:** On the shipment detail page, click **Sync Shipment**. Hitayu ERP fetches the latest status for that AWB from Shiprocket.
- **Sync all shipments:** On the **Shiprocket** page (any tab), click **Sync All**. This refreshes every active shipment in your workspace. Use this sparingly — it may take a few minutes for large order volumes.

## Navigating Shipments by Stage

The **Shiprocket** section in the left sidebar is divided into tabs that group shipments by their current stage:

| Tab | Statuses Shown |
|---|---|
| **New** | pending, created, new |
| **Ready to Ship** | awb_assigned, label_generated |
| **Pickups & Manifests** | manifest_generated, pickup_queued, pickup_scheduled, pickup_exception, picked_up |
| **In Transit** | in_transit, out_for_delivery, reached_destination_hub, ndr, undelivered, exception |
| **Delivered** | delivered |
| **RTO** | rto, rto_in_transit, rto_delivered |
| **All** | Every status |

## Viewing Shipment Tracking Events

Click on any shipment row to open the **Shipment Detail** page. The **Tracking Timeline** section shows every scan event in chronological order — timestamp, location, and event description — exactly as received from the courier's tracking system via webhook.

<Tip>
  You can share the AWB number with your customer so they can track their package directly on the courier's website or the Shiprocket tracking portal.
</Tip>
