The Notifications page is available at `/notifications` and requires the `notifications.view` permission.

The current page is read-only. It shows configured templates and paginated message logs.

## Templates Panel

The templates panel lists each configured notification template.

| Displayed field | Description |
|---|---|
| **Channel / Event** | Channel in uppercase and event name in title case |
| **Template name** | Stored template name |

If no templates exist, the panel shows **No templates configured.**

## Message Logs

The Message Logs table shows:

| Column | Description |
|---|---|
| **Channel** | Notification channel in uppercase |
| **Event** | Event name in title case |
| **Recipient** | Recipient value, or `-` |
| **Status** | Log status |
| **Created** | Log creation timestamp |

Logs are paginated. If no logs exist, the table shows **No notification logs yet.**

## Notification Events

The notification service builds messages for payment link delivery and order received confirmation. Channel delivery is controlled by the Notifications provider gates in **Settings -> Integrations**.
