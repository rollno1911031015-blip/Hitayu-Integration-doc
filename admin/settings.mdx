The Settings area has two related entry points:

| Page | URL | Permission |
|---|---|---|
| **ERP Settings module page** | `/admin/settings` | `settings.integrations.view` or `settings.integrations` |
| **Integration Settings console** | `/settings/integrations` | `settings.integrations.view` or `settings.integrations` |

The integration console is the page used to manage provider credentials and feature gates. Changes require `settings.integrations.manage` or `settings.integrations`.

## Integration Console

The console shows a control-center summary and one card per configured provider.

| Summary metric | Meaning |
|---|---|
| **Providers** | Ready providers compared with total providers |
| **Feature Gates** | Enabled toggles compared with total toggles |
| **Keys Set** | Configured credential keys compared with total credential keys |
| **Missing** | Count of missing required credential keys |

The toolbar supports client-side search and these status filters:

| Filter | Behavior |
|---|---|
| **All** | Shows every provider card |
| **Needs Attention** | Shows providers with missing required keys |
| **Active Toggles** | Shows providers with at least one enabled feature gate |
| **All Quiet** | Shows providers with no missing required keys |

## Provider Cards

Each provider card can contain:

| Section | What it contains |
|---|---|
| **Feature Gates** | Toggle forms that save on change |
| **Delivery Choices** | Select controls that save on change |
| **Commercial Values** | Numeric or text value inputs that save on change |
| **Credential Keys** | Credential input rows with a save button |

Secret credential inputs use password fields and include an eye button to reveal or hide the current value.

## Add Integration Setting

Users with `settings.integrations` can open **Add Integration Setting** and create a dynamic provider key.

The form accepts:

- Provider Key
- Provider Name
- Icon Class
- Setting Key
- Label
- Environment Key
- Value
- Description
- Required flag
- Secret flag

The backend stores provider and setting keys as slugged underscore keys.

## Company Settings

Business identity settings are separate from the integration console.

| Page | URL | Permission |
|---|---|---|
| **Company Settings** | `/masters/company-settings` | `masters.company_settings` |

Company Settings includes company name, legal name, phone numbers, email, website, GST number, PAN number, address fields, bank details, terms, and logo upload.
