Hitayu CRM includes an attendance page where users can start their day, end their day, record breaks, and review attendance records that are visible to them.

<Note>
  Attendance routes require the `employee.attendance` permission.
</Note>

## Opening Attendance

Open **Attendance** from the sidebar or go to `/attendance`.

The page shows:

- Filters for date range.
- An employee filter when the logged-in user can see more than one user through the staff data scope.
- Attendance record cards, newest first.
- Pagination at 20 records per page.

## Starting the Day

The header attendance button posts to `/attendance/punch` with the type `day_start`.

Before the form is submitted, the browser asks for:

- Camera access, so a face photo can be captured.
- Location access, so latitude, longitude, and accuracy can be saved.

When the day is started, the system records:

| Field | Stored value |
|---|---|
| **Check-in time** | Current server time |
| **Latitude / longitude** | Browser geolocation coordinates |
| **Accuracy** | Browser geolocation accuracy, when available |
| **Location name** | Submitted location name, when available |
| **Photo** | Captured image stored under `public/uploads/attendance` |
| **Source** | Submitted source, defaulting to `crm` |

<Warning>
  A user can start the day only once per calendar day. If check-in already exists, the system returns "You have already started your day."
</Warning>

## Ending the Day

The header attendance button posts to `/attendance/punch` with the type used for day end.

Ending the day also requires camera and location capture. The system records checkout time, checkout coordinates, checkout accuracy, checkout location name, and checkout photo.

The system blocks checkout when:

- The user has not started the day.
- The user has already ended the day.

## Breaks

Break punches post to `/attendance/break`.

### Start Break

When a break is started, the system creates an attendance break with:

- Type `professional`.
- Start time.
- Start latitude and longitude.
- Start accuracy and location name when submitted.

The system blocks break start when:

- The user has not started the day.
- The user has already ended the day.
- Another break is already open.

### End Break

When a break is ended, the system updates the open break with end time, end latitude and longitude, end accuracy, and end location name.

The system blocks break end when there is no open break.

## Attendance History

Each attendance record card displays:

| Area | What it shows |
|---|---|
| **User and date** | Employee name and attendance date |
| **Status** | Day Completed when checkout exists, otherwise In Progress |
| **Check-in** | Time, photo, map link, and accuracy when available |
| **Check-out** | Time, photo, map link, and accuracy when available |
| **Breaks** | Start and end time for each break; open breaks show Ongoing |

## Filters

| Filter | Behavior |
|---|---|
| **Employee** | Appears only when more than one visible user is in scope |
| **Date From** | Shows records on or after the selected date |
| **Date To** | Shows records on or before the selected date |
| **Reset** | Clears attendance filters |
