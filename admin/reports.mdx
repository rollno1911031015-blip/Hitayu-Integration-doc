The Reports page in this codebase is an ERP module landing page. It is available at **Admin -> Reports** (`/admin/reports`) and is protected by the `reports.view` permission.

<Note>
  The current implementation does not expose separate order, payment, shipment, or attendance report builders from this route. It also does not provide a report CSV export flow on this page.
</Note>

## What the Page Shows

The page is rendered through the shared ERP module view and displays:

| Area | Current value |
|---|---|
| **Title** | Reports |
| **Subtitle** | Order, payment, team, Shiprocket, NDR, RTO and productivity reports. |
| **Cards** | Configured, Active, Pending Review, Issues |
| **Filter labels** | Status, Owner, Date Range |
| **Table headers** | Module, Purpose, Status, Owner, Action |
| **Default row** | Reports, Dynamic module ready, Configure, Admin, Open |
| **Action labels** | Add, Export, Configure |

The card counts are currently static placeholders from the shared module service.

## Permission

| Permission | What it allows |
|---|---|
| `reports.view` | Opens the Reports module page |

If a user cannot open the page, assign `reports.view` from **Admin -> RBAC**.
