Stock Audit is an Inventory segment used to compare warehouse stock in the system with a physical count.

Open **Admin -> Inventory -> Stock Audit** (`/admin/inventory/stock-audit`).

<Note>
  Creating, saving, and completing stock audits requires both `inventory.stock_audit` and `inventory.manage`.
</Note>

## Create an Audit

The **New Stock Audit** form contains:

| Field | Requirement |
|---|---|
| **Warehouse** | Required. Must be an existing warehouse. |
| **Notes** | Optional. Maximum 2000 characters. |

When **Create Audit** is submitted:

- The audit number is generated as `SA-YYYYMMDDHHMMSS-###`.
- The audit starts in `draft` status.
- The selected warehouse is stored on the audit.
- Every active product variant is added as an audit item.
- Each item's system quantity is copied from that variant's stock in the selected warehouse.
- Audit totals are refreshed.

<Note>
  The implemented flow does not manually add individual products to an audit. Audit items are generated from active product variants when the audit is created.
</Note>

## Recent Audits

The left side of the Stock Audit page shows up to 20 recent audits.

Each list item shows:

| Field | Description |
|---|---|
| **Audit number** | Generated audit identifier |
| **Status** | Draft or Completed |
| **Warehouse** | The audited warehouse |
| **Variance** | Current variance quantity for the audit |

Click an audit to open it with `audit_id` in the query string.

## Audit Summary

The selected audit shows four summary cards:

| Card | Meaning |
|---|---|
| **Audit** | Audit number |
| **System Qty** | Sum of system quantities across audit items |
| **Counted Qty** | Sum of entered counted quantities |
| **Variance** | Sum of item variance quantities |

## Count Sheet

The count sheet table contains:

| Column | Description |
|---|---|
| **Product** | Product name and variant name |
| **SKU** | Item SKU |
| **System** | Quantity recorded for the selected warehouse when the audit was created |
| **Counted** | Physical quantity entered by the user |
| **Variance** | `counted_quantity - system_quantity` |
| **Remarks** | Optional line note, maximum 1000 characters |

Counted quantity must be an integer from `0` to `1000000`. It can be left blank while the audit is still in draft.

## Save Counts

Click **Save Counts** to update counted quantities and remarks.

For each submitted item, the system:

- Stores counted quantity.
- Calculates variance.
- Stores remarks.
- Sets `counted_at` when counted quantity is provided.
- Clears `counted_at` when counted quantity is blank.
- Refreshes audit totals.

Completed audits cannot be changed.

## Complete Audit

Click **Complete Audit** after every audit item has a counted quantity.

The system blocks completion when:

- The audit is already completed.
- Any audit item still has a blank counted quantity.

On completion:

- Items with no variance are skipped.
- Items with a variance call the inventory stock service to set the selected warehouse stock to the counted quantity.
- The stock update source is **Stock Audit**.
- Stock ledger metadata includes audit ID, audit item ID, system quantity, counted quantity, and variance quantity.
- The audit is marked `completed`.
- Completed user and completed time are recorded.

<Warning>
  Completing an audit posts stock changes for variance lines. Check counts carefully before completing, because completed audits are locked.
</Warning>
