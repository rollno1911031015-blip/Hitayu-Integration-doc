Hitayu ERP's calling module lets your team make and receive calls directly from the order management interface, with every call automatically logged against the relevant order or lead. Call outcomes, follow-up notes, and recordings are captured in real time so managers can track team performance and ensure no lead is missed. The IVR integration uses Exotel as the telephony provider and requires a one-time configuration to link your Exotel account to Hitayu.

---

## Prerequisites

Before setting up the IVR integration, make sure you have:

- An active **Exotel account** with a purchased virtual number (ExoPhone).
- An Exotel **App** configured for outbound or click-to-call usage.
- Your **Account SID**, **API Key**, and **API Token** from the Exotel Dashboard.
- Your Hitayu instance accessible via a public HTTPS URL.

<Note>
  Exotel requires your webhook (callback) URL to be publicly accessible over HTTPS. Local development environments will not receive call-status callbacks. Use a tool like ngrok for local testing, or test directly on your staging server.
</Note>

## Step 1 - Enter Credentials in Hitayu

<Steps>
  <Step title="Open IVR integration settings">
    Go to **Settings -> Integrations -> IVR / Calling**.
  </Step>
  <Step title="Fill in your Exotel credentials">

    | Field | Where to Find It | Required |
    |---|---|---|
    | **Account SID** | Exotel Dashboard -> Settings -> API -> Account SID | Yes Yes |
    | **API Key** | Exotel Dashboard -> Settings -> API -> API Key | Yes Yes |
    | **API Token** | Exotel Dashboard -> Settings -> API -> API Token | Yes Yes |
    | **Caller ID** | Your ExoPhone number (the virtual number assigned to your account) | Yes Yes |

    <Warning>
      The **Caller ID** must be the exact ExoPhone number in international format as assigned in your Exotel account (e.g., `+918068xxxxxx`). If it does not match, Exotel will reject outbound call requests.
    </Warning>
  </Step>
  <Step title="Save and verify">
    Click **Save**. Hitayu will display a **Ready** status badge if all fields are valid.
  </Step>
</Steps>

---

## Step 2 - Configure the Call-Status Webhook in Exotel

Exotel sends call lifecycle events (ringing, answered, completed, missed) to Hitayu via a callback URL. You must register this URL in your Exotel App configuration.

<Steps>
  <Step title="Copy the Hitayu call-status webhook URL">
    Your callback URL is:
    ```text
    https://your-hitayu-domain.com/api/webhooks/ivr/call-status
    ```
    <Note>
      Exotel supports both GET and POST callbacks. Hitayu's `/api/webhooks/ivr/call-status` endpoint accepts **both methods** to maintain full compatibility with Exotel's callback system, regardless of which HTTP method your Exotel App is configured to use.
    </Note>
  </Step>
  <Step title="Open your Exotel App settings">
    Log in to the Exotel Dashboard and go to **Apps -> Your App -> Settings**.
  </Step>
  <Step title="Set the Status Callback URL">
    Paste your Hitayu URL into the **Status Callback** field:
    ```text
    https://your-hitayu-domain.com/api/webhooks/ivr/call-status
    ```
  </Step>
  <Step title="Save the App configuration">
    Save the changes in Exotel. From this point forward, every call made through the connected App will send status updates to Hitayu.
  </Step>
</Steps>

---

## Step 3 - Configure the Public Webhook Endpoint

In addition to the `/api/webhooks/ivr/call-status` endpoint, Hitayu also exposes a shorter public webhook path for Exotel compatibility:

```text
https://your-hitayu-domain.com/webhook
```

This endpoint is provided for Exotel configurations that require a root-level URL. Both paths route to the same handler - use whichever fits your Exotel App configuration.

## How Call Logging Works

When a call is placed from Hitayu (via the order or lead profile):

1. Hitayu calls the Exotel API using your Account SID, API Key, and Token to initiate the call.
2. Exotel dials your agent first, then bridges to the customer.
3. As the call progresses, Exotel sends status callbacks to `/api/webhooks/ivr/call-status` with events like `ringing`, `in-progress`, and `completed`.
4. When the call ends, Exotel sends the final status including call duration, a recording URL (if enabled), and the call SID.
5. Hitayu stores the full call record and links it to the order or lead.

Call recordings can be listened to directly from the order communication timeline in Hitayu.

## Agent Profile Management

Each Hitayu user who makes calls needs their mobile number registered so Exotel can ring them first in the two-leg call flow.

To configure agent numbers:
1. Go to **Settings -> Team -> Users**.
2. Open the agent's profile.
3. Enter their mobile number in the **Calling Number** field.
4. Save the profile.

<Tip>
  Agents can also update their own calling number from **My Profile -> Calling Settings** without needing admin access.
</Tip>

## Call Outcomes and Follow-Ups

After every call, Hitayu prompts the agent to log an outcome before the call record is closed:

| Outcome | Description |
|---|---|
| **Confirmed** | Customer confirmed the order |
| **Cancelled** | Customer cancelled the order |
| **Call Back** | Customer requested a callback at a later time |
| **Not Answered** | Call was not picked up |
| **Wrong Number** | Invalid or wrong customer number |
| **Follow Up** | Requires further follow-up action |

When **Call Back** or **Follow Up** is selected, the agent can set a follow-up date and time. Hitayu will resurface the order in the calling queue at the scheduled time.

## Troubleshooting

| Symptom | Likely Cause | Fix |
|---|---|---|
| Calls not initiating | Invalid API Key, Token, or Account SID | Verify all three credentials in Settings -> Integrations -> IVR |
| Wrong number displayed to customer | Caller ID not set correctly | Confirm Caller ID matches your Exotel ExoPhone exactly |
| Call status not updating in Hitayu | Webhook URL not registered in Exotel App | Add the callback URL to your Exotel App's Status Callback field |
| Call recordings not appearing | Recording not enabled in Exotel App | Enable recording in your Exotel App settings |
| Duplicate call log entries | Exotel re-sent the callback | No action needed - Hitayu deduplicates call-status events |
