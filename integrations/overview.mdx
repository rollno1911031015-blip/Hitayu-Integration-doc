Hitayu CRM integrates with Shopify, Shiprocket, payment gateways, WhatsApp, SMS Wale, and Exotel IVR. Integration credentials and feature gates are managed from the integration console.

## Where to Configure Integrations

Open **Settings -> Integrations** (`/settings/integrations`).

| Permission | Access |
|---|---|
| `settings.integrations.view` or `settings.integrations` | View the integration console |
| `settings.integrations.manage` or `settings.integrations` | Save provider settings, toggles, choices, values, and keys |

## Console Status

Provider cards show credential readiness based on required keys.

| Status | Meaning |
|---|---|
| **Ready** | All required credential keys for that provider are configured |
| **Missing** | One or more required credential keys are empty |

The console also shows counts for providers, feature gates, configured keys, and missing required keys.

## Webhook Routes

Webhook routes are grouped under `/api/webhooks/` for API integrations. The IVR public webhook also exists at `/webhook`.

| Category | Implemented routes |
|---|---|
| **Shopify** | Orders, refunds, checkouts, products, customers, inventory levels, locations |
| **Shiprocket / carrier** | Tracking, NDR, SR checkout abandoned, carrier tracking |
| **Payment** | Razorpay, Cashfree, PayU |
| **Notifications** | WhatsApp status, SMS status |
| **IVR** | `/api/webhooks/ivr/call-status` and `/webhook` |
| **Leads** | `/api/webhooks/leads/{source}` |

See [Webhook Reference](/integrations/webhooks) for the exact paths.

## Setup Checklist

<Steps>
  <Step title="Enter credentials">
    Open `/settings/integrations` and save the required provider keys.
  </Step>
  <Step title="Enable feature gates">
    Turn on only the sync or webhook gates that should run in this deployment.
  </Step>
  <Step title="Register webhook URLs">
    Add the relevant `/api/webhooks/...` URLs in Shopify, Shiprocket, payment gateway, Meta, SMS provider, or Exotel dashboards.
  </Step>
  <Step title="Test one event">
    Trigger one test event for the provider and confirm the expected CRM record or log is created.
  </Step>
</Steps>
